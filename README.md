# TimeWise

TimeWise is a desktop-based appointment scheduler developed in C# using WPF for the Windows operating system. It allows users to manage appointments through a simple and responsive interface. TimeWise is designed for individuals or small businesses who need a reliable, offline scheduling tool without reliance on subscriptions or internet connectivity.
TimeWise enables users to create, modify, and delete appointments, view their schedule in daily or weekly formats, and receive reminders. It supports local data storage via SQLite and offers features such as search, CSV export, and color-coded categories for better organization.
